A compact chess engine in 4 KB of Python: 0x88 board, negamax with alpha-beta and quiescence, fixed 250,000-node budget per move, incremental material + piece-square evaluation, MVV-LVA and killer move ordering. It plays the house gauntlet over HTTP, fully deterministic — no clock, no randomness.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
